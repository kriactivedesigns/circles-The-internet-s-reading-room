## Step 1 — Import tokens.json into Figma

1. Install the **Tokens Studio** plugin (free) from the Figma Community
2. Open Figma → Plugins → Tokens Studio for Figma
3. Click **Load from file** → select `tokens/tokens.json`
4. You will see token sets: `global`, `semantic-dark`, `semantic-light`, `component`
5. Enable `global` + `semantic-dark` as your active theme
6. Click **Create Styles** → Tokens Studio will generate:
   - All color styles (Figma Styles panel)
   - All text styles
   - All effect styles (shadows/glows)
7. To switch to light mode: enable `semantic-light` instead of `semantic-dark`

---

## Step 2 — Import icon SVG

1. In Figma, create a new page called `Icons`
2. Drag `circles-icons.svg` directly into the canvas
3. The SVG imports as a grouped frame
4. Select all → **Ungroup** (Cmd+Shift+G twice)
5. Each icon is now a 24×24 frame
6. Select each icon group → **Create Component** (Cmd+Alt+K)
7. Name components as: `Icon/feed`, `Icon/lobby`, `Icon/shelf` etc.
8. Move to your component library page

## Token naming convention

`{category}.{subcategory}.{variant}`

Examples:
- `color.blue.200` → #7DBCFF (brand)
- `component.button.primary-radius` → pill (50px)
- `duration.ambient` → 2400ms (avatar glow)

## Logo animation spec

The circles logo has three elements:
1. **Outer ring** — fixed, never animates. Stroke: 0.9px, color: #7DBCFF
2. **Inner ring A** — starts at t=0.15, expands to outer radius
3. **Inner ring B** — starts at t=0.65, expands to outer radius (offset by 0.5)

Alpha formula: `(1 - Math.pow(t, 0.6)) * 0.55`
t increment per frame: 0.004 (at 33ms interval = ~30fps)
In Figma: use Smart Animate prototype with 3 frames per ring cycle

## Background flow lines

12 Bezier curves, each top-to-bottom:
- Stroke: 0.8px, color: #7DBCFF
- Opacity: 6–13% (dark mode)
- In Figma: draw 12 curved vectors, set opacity individually, group as `BG/FlowLines`
- For animation: export as Lottie via AE or use Figma prototype

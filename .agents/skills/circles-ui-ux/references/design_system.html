08 — Motion & Animation
Animation System
All animations are ambient and unhurried. They must never compete with content or reading. Hover each card to trigger the animation preview.
Float (Sandbox Personas)
6s ease-in-out · translateY(0 → -10px) · infinite
.animate-float-slow { animation: float 6s ease-in-out infinite }
.animate-float-delayed { animation-delay: 3s }
Collision Pulse (Avatar Ring)
2s cubic-bezier(0.4,0,0.6,1) · glow intensity cycles · infinite
0%: shadow 0 0 15px rgba(92,148,233,0.5)
50%: shadow 0 0 30px rgba(92,148,233,0.8)
Logo Ripple
3s cubic-bezier(0.25,1,0.5,1) · scale 0.2→1 · 1.5s stagger
0%: scale(0.2) opacity(1)
100%: scale(1) opacity(0)
View Transition
0.4s ease · opacity + scale(0.98→1)
.hidden-view: opacity 0, scale 0.98
.active-view: opacity 1, scale 1
Ambient Orbs
mousemove tracking · ±30px max · transition 1000ms ease
blur: 80px–120px
cursor tracking: ±30px offset
transition: 1000ms ease
Nav Collapse (on scroll)
0.3s cubic-bezier(0.4,0,0.2,1) · labels hide · pill shrinks
